# Scooter Home

A phone app (PWA) for Xiaomi scooters: GPS ride tracker, speed alert, parking finder,
battery and range estimate, trip planner, charging calculator, ride stats,
maintenance tracker, expenses and achievements.

Open: https://goodfellow73.github.io/scooter-home/ in Chrome on Android, then
⋮ → Add to Home screen.

The Lock, Headlight, riding mode and max speed controls are a preview only:
they don't send commands to the scooter.
